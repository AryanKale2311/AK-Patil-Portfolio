# Akshat Patil — Parody Portfolio

Responsive cream-and-white satirical portfolio for a friendly private joke.

## Files
- `index.html` — content and structure
- `style.css` — responsive design
- `script.js` — mobile navigation and scroll reveal
- `assets/` — optional approved profile photo

## Publish on GitHub Pages
1. Create a repository, e.g. `akshat-parody`.
2. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for GitHub Pages to publish.

## Optional portrait
Only use a photo Akshat has shared with permission. Put a real JPEG at `assets/profile.jpg`. Replace the `.placeholder` element in `index.html` with:
`<img src="assets/profile.jpg" alt="Akshat Patil" class="profile-photo">`
Then add `.profile-photo{width:100%;height:355px;object-fit:cover;object-position:center}` to `style.css`.

## Tone
This is friendly satire. Metrics are explicitly fictional; the final section reveals the joke. Do not add private contact details or present fake metrics as genuine credentials.
